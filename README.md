# TraceMail AI 🔐

**AI-Assisted Email Threat Detection and Forensic Intelligence Platform**

TraceMail AI is a cybersecurity prototype that analyzes email evidence to identify potential threats and help explain suspicious activity.

## Features

- Email threat classification
- SPF, DKIM, and DMARC authentication-result analysis
- Sender identity and email-content analysis
- Suspicious URL and domain detection
- IP infrastructure and email-routing visualization
- Evidence correlation and explainable threat indicators
- Interactive dashboard for email investigation

## Technologies Used

- Python
- Flask
- HTML and CSS
- JavaScript
- Leaflet and OpenStreetMap

## Getting Started

1. Clone the repository:

   `git clone https://github.com/YOUR-USERNAME/TraceMailAI.git`

2. Open the project folder:

   `cd TraceMailAI`

3. Install the dependencies:

   `pip install -r requirements.txt`

4. Start the application:

   `python app.py`

5. Open `http://127.0.0.1:5000` in your browser.

## Disclaimer

This project is an educational cybersecurity prototype. IP geolocation represents approximate network infrastructure locations and does not establish a person's physical location. Classification results are indicative and should not be treated as definitive proof of malicious activity.
